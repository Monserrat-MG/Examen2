01 · FUNDAMENTOS DE JAVASCRIPT

El lenguaje que agrega interactividad.

Conceptos, variables, datos, operadores y estructuras para construir instrucciones.

¿Qué es JavaScript?

JavaScript es un lenguaje de programación que permite agregar comportamiento e interactividad a las páginas web. Puede responder a clics, validar formularios, modificar el contenido y trabajar con datos.

console.log("¡Hola, WEBVERSE!");

Declaración de variables y constantes

let declara una variable cuyo valor puede cambiar; const declara una referencia que no puede reasignarse. var es una forma antigua que todavía puede encontrarse.

let nombre = "Monse";
let puntos = 10;
const materia = "Aplicaciones Web";
var mensaje = "¡A crear!";

Tipos de datos

  • String: texto, por ejemplo "Hola".
  • Number: números enteros y decimales.
  • Boolean: verdadero o falso.
  • Undefined: valor no asignado.
  • Null: ausencia intencional de valor.
  • Object: objetos, arreglos y otras estructuras.
  • BigInt y Symbol: tipos adicionales.
let texto = "WEBVERSE";
let cantidad = 18;
let activo = true;
let datos = null;

Operadores

Aritméticos: +, -, *, /, %, **. Asignación: =, +=, -=. Comparación: ==, ===, !=, !==, >, <, >=, <=. Lógicos: &&, ||, !. También existe el operador ternario condición ? valor1 : valor2.

let suma = 8 + 4;
let esMayor = suma > 10;
let puedeEntrar = esMayor && true;

Cuadros de diálogo

JavaScript incluye alert() para mostrar mensajes, prompt() para solicitar un dato y confirm() para pedir confirmación.

Prueba los cuadros de diálogo.

Obtener datos de un formulario

Se pueden leer los valores mediante value, usando el evento submit y evitando que el formulario recargue la página con preventDefault().

parseInt() y parseFloat()

parseInt() convierte una cadena a un número entero; parseFloat() permite obtener un número decimal. Si el texto no comienza con un número válido, devuelven NaN.

Resultado aquí.
parseInt("24.75")   // 24
parseFloat("24.75") // 24.75

Estructuras de control

Las estructuras de control determinan qué instrucciones se ejecutan y en qué orden. Entre ellas están las condiciones y las estructuras de selección.

// if
if (llueve) {
  console.log("Llevar paraguas");
}

// if / else
if (nota >= 6) {
  console.log("Aprobado");
} else {
  console.log("Seguir practicando");
}

// switch
switch (dia) {
  case 1: console.log("Lunes"); break;
  default: console.log("Otro día");
}

Funciones en JavaScript

Una función es un bloque reutilizable que realiza una tarea. Puede recibir parámetros y devolver un resultado con return.

function saludar(nombre) {
  return "¡Hola, " + nombre + "!";
}

const mensaje = saludar("Monse");
02 · DOCUMENT OBJECT MODEL

DOM: JavaScript puede modificar la página.

El DOM representa el documento HTML como un árbol de objetos. JavaScript puede localizar elementos y cambiar su contenido, atributos o estilos.

getElementsByTagName()

Obtiene una colección de elementos que comparten el nombre de etiqueta indicado.

document.getElementsByTagName("p");

getElementsByClassName()

Obtiene una colección de elementos que tienen una clase determinada.

document.getElementsByClassName("lesson-card");

querySelector()

Devuelve el primer elemento que coincide con un selector CSS.

document.querySelector("#domTitle");

querySelectorAll()

Devuelve una lista de todos los elementos que coinciden con el selector CSS.

document.querySelectorAll(".demo-button");

DOM en acción · Cambia este mensaje

Este texto será modificado desde JavaScript utilizando el DOM.

document.querySelector("#domMessage").textContent = "Nuevo texto";

Métodos en HTML y JavaScript

Los métodos permiten realizar acciones sobre objetos. En HTML se utilizan atributos y eventos para conectar elementos con JavaScript; en JavaScript se invocan métodos como .addEventListener(), .focus(), .classList.add() y .textContent para interactuar con la página.

<button id="miBoton">Presióname</button>

const boton = document.querySelector("#miBoton");
boton.addEventListener("click", () => {
  boton.textContent = "¡Evento detectado!";
});

04 · DISEÑO ADAPTABLE

Una web, muchas pantallas.

Flexbox, Grid y Media Queries ayudan a organizar los elementos y adaptar el diseño a computadoras, tabletas y celulares.

Media Query

Permite aplicar estilos CSS cuando se cumple una condición, por ejemplo, cuando la pantalla tiene un ancho máximo determinado.

/* Para pantallas de 600px o menos */
@media (max-width: 600px) {
  .contenedor {
    grid-template-columns: 1fr;
  }
}

Flexbox

Modelo de diseño unidimensional: organiza elementos en una fila o columna y facilita su alineación y distribución.

.contenedor {
  display: flex;
  justify-content: center;
  align-items: center;
  gap: 12px;
  flex-wrap: wrap;
}

CSS Grid

Modelo bidimensional que organiza elementos mediante filas y columnas.

.contenedor {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 12px;
}

Tipos de pantallas

Los diseños suelen considerar diferentes tamaños y contextos de visualización:

  • Escritorio o computadora.
  • Tableta.
  • Teléfono móvil.

Diseño responsivo

Un diseño responsivo adapta la distribución, el tamaño y el espacio de los elementos para que el contenido sea cómodo de utilizar en diferentes dispositivos. Se apoya en diseños flexibles, imágenes adaptables y Media Queries.

img { max-width: 100%; height: auto; }

.contenedor {
  width: min(100% - 2rem, 1100px);
  margin-inline: auto;
}

@media (max-width: 700px) {
  .columnas { grid-template-columns: 1fr; }
}
